# Emall Client（E-MALL 前台买家商城）

基于 **Vue 3 + TypeScript + Vite + Pinia + Element Plus** 构建的 B2C 现代化买家端应用（默认开发端口：`5173`）。

## 常用命令

```bash
# 安装依赖
npm ci

# 启动本地开发服务 (http://localhost:5173)
npm run dev

# 运行 Vitest 单元测试
npm test

# 类型检查与生产环境打包
npm run build
```

完整架构说明、联调方式与全栈启动流程请参见项目根目录 [`../README.md`](../README.md)。
