# Emall Admin（E-MALL 运营管理后台）

基于 **Vue 3 + TypeScript + Vite + Pinia + Element Plus + Apache ECharts** 构建的全域运营管理后台（默认开发端口：`5174`）。

## 常用命令

```bash
# 安装依赖
npm ci

# 启动本地开发服务 (http://localhost:5174)
npm run dev

# 运行 Vitest 单元测试
npm test

# 类型检查与生产环境打包
npm run build
```

完整架构说明、RBAC 权限分级与全栈启动流程请参见项目根目录 [`../README.md`](../README.md)。
